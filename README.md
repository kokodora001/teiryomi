# あそびば（ティアよみ / 絵描き人狼）

友達とオンラインで遊べるパーティーゲーム集です。トップページ（index.html）でゲームを選びます。

- **ティアよみ**：出題者のティア表をみんなで予想する（tier.html）
- **絵描き人狼**：1人だけお題を知らない人狼を、みんなの一筆から見つけ出す（ekaki.html）
- **えしりとり**：絵だけでつなぐ伝言しりとり（eshiri.html）
- **ドット＆ボックス**：線を引いて四角を取り合う陣取り（dots.html）
- **お絵かき伝言**：お題→絵→答え→絵…と伝言していく（dengon.html）
- **同時陣取り**：全員同時にマスを選ぶ陣取り。ぶつかったら岩（jintori.html）
- **フルーツまぜまぜ**：同じ果物をくっつけてスイカを目指す落ち物パズルの対戦（fruit.html）
- **ナンプレバトル**：同じナンプレを同時に解く早解き対戦（sudoku.html）

## 時間切れ・スマホの一時停止への対策（v1.7.2〜：お絵かき伝言・えしりとり）

- 描いている絵・入力中の言葉は、線を引くたびに部屋へ「下書き」として保存されます
- 時間切れのときに提出されていない人は、下書き（そこまで描いた絵）がそのまま提出されます。スマホで別アプリに切り替えた・画面を消した場合も同じ
- 進行役はふだんホストですが、ホストのスマホが止まっていても、ほかの人の画面が数秒遅れて代わりにゲームを進めます（答え合わせ中も、20秒反応がなければ「代わりにめくる」ボタンが出ます）

## スマホでの誤選択対策（v1.7.1〜）

長押しやお絵描き中に画面全体が青く選択されないよう、入力欄以外では文字選択・長押しメニュー・ドラッグを無効にしています（style.css の末尾と common.js の先頭）。入力欄ではこれまでどおり選択・コピーできます。

## ロビー（v1.5〜）

トップで「ロビーを作る」→ 友達に部屋コードを送る → ホストがゲームを選んで「〇〇で遊ぶ！」で全員がそのゲームへ移動します。
ゲーム中にホストが「🎮 ゲームを変える」を押すと、全員が同じ部屋のままロビーに戻り、別のゲームを選べます（得点はゲームごとにリセット）。
部屋コードは全ゲーム共通で、どの画面で入力しても正しいゲーム（またはロビー）に移動します。各ゲームのページから直接部屋を作って遊ぶこともできます。
GitHub Pages（画面）＋ Firebase Realtime Database（通信）で動きます。サーバーを立てる必要はありません。

## まずは手元で動作確認（Firebase不要）

`firebase-config.js` が空のままだと **ローカルテストモード** で動きます。
同じブラウザの複数タブ同士で通信するので、1人で全フェーズを確認できます。

```bash
cd tieryomi
python3 -m http.server 8000
```

1. タブ1で http://localhost:8000 を開いて「部屋を作る」
2. 「リンクをコピー」したURLを別タブで開いて参加（タブ3つ以上でもOK）
3. ゲームスタート

> ES Modules を使っているので、`index.html` をダブルクリックで開く（file://）のは不可です。

## 本番（友達とオンラインで遊ぶ）セットアップ

### 1. Firebase プロジェクトを作る
1. https://console.firebase.google.com で「プロジェクトを追加」
   （Googleアナリティクスはオフで大丈夫）
2. 左メニュー「構築」→「Realtime Database」→「データベースを作成」
   - ロケーション：シンガポール（`asia-southeast1`）が日本から近いです
   - 「ロックモード」で開始してOK（次の手順でルールを上書きします）
3. 「ルール」タブを開き、`database.rules.json` の中身を貼り付けて「公開」

### 2. Webアプリを登録して設定をコピー
1. プロジェクトの設定（⚙️）→「マイアプリ」→ `</>`（ウェブ）を追加
2. 表示される `firebaseConfig` の値を `firebase-config.js` に貼り付け
   - **`databaseURL` が必ず入っていること**を確認してください（無いとローカルモードになります）
   - 見当たらない場合は Realtime Database の画面上部に出ている URL をコピーして追加

> apiKey などは公開されても問題ない値です（Firebaseのクライアント設定は元々公開前提）。アクセス制御はルール側で行います。

### 3. GitHub Pages で公開
1. GitHub で新しいリポジトリを作り、このフォルダの中身を全部アップロード
2. Settings → Pages → Source を「Deploy from a branch」、ブランチ `main` / `/(root)` にして Save
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

### 4. 遊び方
- 1人が「部屋を作る」→ 招待リンク（またはコードの4文字）を友達に送る
- 2人以上そろったらホストが「ゲームスタート」

## お絵かき伝言の仕様

- **流れ**：📝お題を書く → 🖍描く → 💬当てる → 🖍描く → … → 1列ずつ答え合わせ（全員同時進行）
- **ターンごとに別の制限時間**：お題 20/30/60秒/なし、描く 60/90/120秒/なし、当てる 20/30/60秒/なし（時間切れはその時点の内容で自動提出。お題が空なら「おまかせ」）
- **振り分け**：列はターンごとにランダムな人へ。ただし自分が書いたお題・一度関わった列は回ってこない（1列に同じ人は1回だけ）
- **長さ**：全員分（人数−1ターン）か、4・6ターンまで
- **得点**：絵が伝わる（答えが描いたお題と一致）たびに描いた人 +1・当てた人 +1。ほぼ同じ答えは答え合わせ中に誰でも⭕にできる。❤️いいね、称号、最初のお題が最後まで伝わったら🎉

## ナンプレバトルの仕様

- **配布**：ホストがスタートすると、答えが1つに決まる盤面を自動で作り、3秒カウントダウンのあと全員に同じ盤面を同時に表示（カウント中は隠す）
- **むずかしさ**：かんたん（ヒント40個）／ふつう（32個）／むずかしい（26個前後）／ごくむず（21〜24個。答えが1つのまま限界まで削り、「この数字しか入らない」系の簡単な考え方だけでは解けない問題だけを選ぶ）
- **判定**：数字を入れた瞬間に正誤判定。まちがえると数字は入らず、ペナルティ加算
- **ペナルティ**：ミスするたびに増える。1回目 +N秒、2回目 +2N秒、3回目 +3N秒…（N は 5/10/15秒から選択）
- **勝敗**：タイム（解き終わるまでの時間＋ペナルティ合計）がいちばん短い人の勝ち。まだ解いている人が1位のタイムを超えて逆転できなくなった時点で終了
- **画面**：みんなの進み具合（％・ミス回数・クリアタイム）を表示。✏️メモ、同じ数字・行・列・ブロックのハイライト、残り個数つき数字パッド。PCは数字キー・矢印・Backspace・M
- **その他**：ギブアップ可。リロードしても入れた数字とミス回数は復元（メモはその端末に保存）

## フルーツまぜまぜの仕様

- **ルール**：同じ果物どうしがくっつくと1段大きい果物に（さくらんぼ→いちご→ぶどう→みかん→かき→りんご→なし→もも→パイナップル→メロン→スイカ）。果物がラインを越えたまま止まるとゲームオーバー
- **対戦**：1〜10人。3秒カウントダウンで全員同時スタート。落ちてくる果物の順番は全員同じ
- **勝敗**：スイカを作った人がその場で勝ち（全員終了）。スイカが出ないまま全員ゲームオーバーならスコア勝負。制限時間（3/5/10分/なし）も選べる
- **得点**：合体でできた果物のレベルに応じて 1, 3, 6, 10, … 点
- **画面**：ほかの人の箱が小さく見える。PCは ← → とスペースでも操作可。リロードしても自分の箱は復元
- 物理演算に Matter.js（MIT License）を同梱（`matter.min.js`）

## 同時陣取りの仕様

- **人数・盤**：2〜6人。盤は人数で自動（2人 7×7、3〜4人 9×9、5〜6人 11×11）。スタートは四隅と辺の真ん中
- **1ターン**：全員が同時に、自分の陣地の上下左右にある空きマスを1つ選ぶ（結果が出るまで変更OK）
- **判定**：自分だけが選んだマス → 陣地／2人以上が同じマス → 岩（誰のものでもない）
- **囲い込み**：空きマスのかたまりに接しているプレイヤーが1人だけなら、そのかたまりはまるごとその人のもの（盤の端・岩も壁になる）
- **得点**：陣地1マス=1点、★マス=3点。15/20/30ターンか「埋まるまで」。誰も動けなくなっても終了
- **時間**：1ターン 10/15/30秒/なし。時間切れ・切断中の人は選べるマスからランダム
- **結果**：順位・通算勝利数、称号（囲い込み名人・ぶつかり王・スターハンター）

## ドット＆ボックスの仕様

- **人数**：2〜6人（7人目以降は観戦）。手番の順番は毎回シャッフル
- **ルール**：順番に線を1本引く。四角の4辺目を引いたらその四角をもらい、もう1手。全部引き終わったら四角の多い人の勝ち
- **盤**：3×3〜6×6。制限時間 15/30/60秒/なし（時間切れは自動で1本。取れる四角があれば取り、なければ相手に渡さない線を選ぶ）
- **操作**：PCはクリック1回。スマホは1回目のタップで選択、同じ線をもう一度タップで決定（3辺目になる線は赤く表示）
- **切断**：切断中の人の番はホストの画面が自動で進める
- **結果**：順位と通算勝利数（🏆）。「もう一戦」で何戦でも

## えしりとりの仕様

- **流れ**：全員が同時に自分の列を始める（スタートの文字はランダム）→ ステップごとに列がランダムな人へ回る（自分の列・一度関わった列は来ない） → 届いた絵が何に見えるか答え、その最後の文字から始まる言葉を描く → 最後の人は答えるだけ → 1列ずつ答え合わせ
- **人数・長さ**：3〜10人。1列の長さは「全員分（人数−1枚）」か「4枚まで」「6枚まで」。制限時間は 60/90/120秒/なし（時間切れはその時点の内容で自動提出）
- **言葉のルール**：ひらがな・カタカナで入力。「ん」で終わる言葉は描けない（答えが「ん」で終わったらひとつ前の文字から）。濁点・小さい文字のあり・なしは区別しない
- **得点**：絵が伝わる（答えが描いた言葉と一致）たびに、描いた人 +1・答えた人 +1。ほぼ同じ答え（例：いぬ／こいぬ）は答え合わせ中に誰でも「⭕」にできる
- **その他**：絵に❤️（いいね）／称号（画伯賞・伝える力・解読王）／いいねが多かった絵のギャラリー／何ラウンドでも続けられ、合計点で順位

## 絵描き人狼の仕様

- **お題の決め方**：「おまかせ」（全員参加・36ジャンル720語からランダム、3人〜）／「出題者が決める」（交代で1人が出題者になり描かずに見守る、4人〜）
- **流れ**：役職カードをめくって確認 → 順番に一筆ずつ描く（1〜3周）→ 投票 → 人狼が単独最多票なら人狼がお題を回答 → 結果
- **一筆**：指（マウス）を離すまでが一筆。離したあと「描き直す」か「決定」を選べる。描いている途中の線も他の人にリアルタイムで見える
- **人狼の回答**：ひらがな・カタカナ・別表記（例：りんご／林檎）は自動で正解判定。一致しない場合は人狼以外の誰かが「正解／不正解」を判定
- **得点**：人狼の勝ち → 人狼 +3 ／ 市民の勝ち → 市民 +1 ／ 勝敗に関係なく人狼に投票した市民 +1
- **戦犯投票**：市民が負けたときだけ、結果画面で参加者全員（人狼も）が「市民の誰か」か「戦犯なし」に投票。単独最多の人は −2点（同票・「戦犯なし」最多なら減点なし）。最終結果に称号「😇戦犯」
- **その他**：人狼は1番手にならない／投票画面で名前をタップするとその人の線だけ表示／結果画面で描いた順に再生／最終結果に全ゲームの絵のギャラリー
- お題の追加は `ekaki-presets.js` に。`'りんご|林檎|リンゴ'` のように「|」区切りで別表記を書くと自動判定の対象になります

## ティアよみの仕様

- **進行**：お題決め → ティア作成（出題者と予想者が同時に）→ 全員提出で自動的に正解発表 → 次の出題者へ
- **得点**：段がぴったり +3 ／ 1段ズレ +1 ／ 5つ全部ぴったりでボーナス +5（1問最大20pt）。出題者はその回0pt
- **周回**：ロビーで 1〜3周 / エンドレス を選択。全員が規定回数出題したら最終結果へ
- **ホスト**：参加順で最初のオンラインの人。抜けると自動で次の人に移ります
- **切断対策**：リロードしても同じタブなら自動復帰・作りかけのティア表も保持。
  切断した人がいる場合、ホストは「待たずに発表」「出題を次の人へ回す」ができます
- **途中参加**：お題が出た後に入った人はその回だけ観戦、次のお題から参加
- **最終結果**：表彰台・称号（一番の理解者／ニアピン王／エスパー／読まれやすい人／ミステリアス）・全問のふりかえり

## 注意点

- 身内向けの作りなので、開発者ツールを使えば提出前に他人の回答を覗くことは技術的に可能です
- 部屋データは自動では消えません。気になったら Firebase コンソールの「データ」タブで `rooms` を削除してください（無料枠の容量にはまず届きません）
